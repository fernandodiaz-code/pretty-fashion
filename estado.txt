Actualizado: 2026-07-01
Ubicacion: Isla Decepcion 204, Comuna de Lo Prado, Santiago de Chile

=== CONTEXTO DEL NEGOCIO ===
- Nombre correcto del local: Gas Orteguita
- Rubro: Venta/recarga de gas abastible (Gas Licuado)
- Productos: galones de 5kg, 11kg, 15kg y 45kg
- No se manejan articulos tipo retail; el inventario se controla por peso y estado del galon
- Estados relevantes: lleno, vacio y concho
- "Concho" = galon que el cliente trae y aun conserva un poco de gas

=== MODELO DE VENTA ===
- La operacion se registra como venta
- El cliente trae un galon vacio o con concho
- Se le entrega un galon lleno del mismo peso
- La venta siempre debe respetar el mismo peso: 5kg por 5kg, 11kg por 11kg, 15kg por 15kg, 45kg por 45kg
- Los precios dependen del peso y pueden cambiar con el tiempo
- El sistema no usa boleta ni impresion termica por ahora
- El flujo distingue ventas en local y ventas en camion
- La diferencia principal entre ambos caminos es como se aplican los descuentos QR

=== LOGICA DE INVENTARIO ===
- En una venta:
  * Cliente trae vacio -> llenos -1, vacios +1
  * Cliente trae concho -> llenos -1, conchos +1
- En pedidos a central:
  * El local pide galones llenos
  * El local debe entregar galones vacios
- El panel de inventario permite revisar stock y ajustar cantidades por peso

=== TECNOLOGIAS ===
- Backend: Django 5.2.1 con Python
- Base de datos actual: SQLite en db.sqlite3
- Objetivo futuro: Supabase/PostgreSQL
- Frontend: Django Templates + Bootstrap 5.3.3 + jQuery
- Sin consultas MySQL raw; usar ORM Django

=== USUARIOS Y ROLES ===
- Usuario administrador local de desarrollo: crear con manage.py createsuperuser
- El usuario admin fue configurado como is_staff=True e is_superuser=True
- Regla de roles:
  * is_staff=True -> Administrador, accede a todo
  * is_staff=False -> Vendedor, accede principalmente a realizar ventas
- El login redirige segun rol:
  * Administrador -> /jefatura/
  * Vendedor -> /ventas/venta/
